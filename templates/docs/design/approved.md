# Approved patterns

Solutions this product has settled on. A role proposing something in the same territory reuses these instead of re-deciding — and when it deliberately departs from one, it says so and why.

An entry earns its place after the decision proved itself in use, not when it was first drawn.

## Entry format

Copy this block per pattern:

```
### <name of the pattern>

- **Where it lives:** <screen, component, or flow>
- **Applies when:** <the situation that triggers it — not the screen it first appeared on>
- **Rationale:** <why this and not the alternatives, in one or two sentences>
- **Evidence:** <screenshot path, URL, or where to look>
- **Settled:** <date>
```
